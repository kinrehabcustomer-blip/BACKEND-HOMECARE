## 1. บทนำ

### 1.1 วัตถุประสงค์
ระบบใช้บริหารงานดูแลผู้สูงอายุและผู้ป่วยที่บ้านของ KIN Homecare ครบวงจรในที่เดียว ตั้งแต่รับลูกค้า เปิดเคส จัดตารางกะ และพนักงานเช็คอินหน้างาน ไปจนถึงรายงานอาการ แจ้งญาติ เก็บเงินลูกค้า และจ่ายค่าตอบแทนพนักงาน

### 1.2 ปัญหาที่ระบบต้องแก้

| ปัญหาเดิม | สิ่งที่ระบบต้องทำ |
| --- | --- |
| ไม่รู้ว่าพนักงานไปถึงบ้านลูกค้าจริงไหม | บันทึกเช็คอินด้วยพิกัด GPS + เซลฟี่ + เวลาเครื่องแม่ข่าย |
| นับกะและค่าจ้างจากสมุด/Excel | ตั้งค่าจ้างต่อเคส ปล่อยเป็นงวด และรวบเข้ารอบจ่าย |
| ไม่รู้ว่าวันนี้ใครไปบ้านไหน | ตารางกะรายวัน ปฏิทิน และมุมมองรายคน |
| ประวัติแพ้ยา/โรคประจำตัวอยู่ในกระดาษ | แฟ้มผู้รับการดูแลที่พนักงานเปิดดูได้ก่อนเข้าบ้าน |
| ญาติต้องโทรถามอาการ | ญาติรับรายงานและแชทกับทีมผ่าน LINE |
| รู้ว่ามีงานค้างตอนมีคนบ่นแล้ว | แจ้งเตือนเชิงรุก ทั้งอีเมลสรุปทุกเช้าและกระดิ่งในระบบ |

### 1.3 ขอบเขต
**อยู่ในขอบเขต:** บริหารพนักงาน ลูกค้า ผู้รับการดูแล เคส กะ การเข้างาน รายงานการดูแล ใบแจ้งหนี้และการรับชำระ ค่าตอบแทนพนักงาน แพ็กเกจราคา การประเมินจากญาติ การเชื่อมต่อกับ LINE และการแจ้งเตือน

**นอกขอบเขต:**
- ส่งข้อความ LINE โดยตรง (ระบบแชท chat.kinorigin.com เป็นผู้ส่ง)
- ภาษีมูลค่าเพิ่ม (ธุรกิจไม่ได้จด VAT)
- ตัดเงินผ่าน payment gateway
- บัญชีแยกประเภท
- เงินเดือนประจำของพนักงานออฟฟิศ

## 3. ภาพรวมกระบวนการทางธุรกิจ

```
ลูกค้า/ผู้รับการดูแล → เปิดเคส (+ใบแจ้งหนี้ร่างอัตโนมัติ) → มอบหมายพนักงาน → จัดกะ
   → พนักงานเช็คอิน/รายงาน/เช็คเอาท์ → ญาติได้รับรายงานทาง LINE → ตรวจและยืนยันกะ
   → (ระหว่างนั้น) ออกใบแจ้งหนี้ → รับชำระ/สลิป
   → (ระหว่างนั้น) ปล่อยงวดค่าจ้าง → เปิดรอบจ่าย → บันทึกจ่าย → พนักงานเห็นสลิป
   → ปิดเคส → ญาติยังเข้าดูได้อีก 30 วัน
```

ข้อกำหนดหลักของกระบวนการ:
- งานเงินทั้งสองฝั่ง (เก็บเงินลูกค้าและจ่ายพนักงาน) ต้องทำได้ระหว่างให้บริการ ไม่ต้องรอปิดเคส
- การปิดเคสต้อง **ไม่** ปล่อยค่าจ้างหรือบันทึกรับเงินให้อัตโนมัติ
- การยืนยันกะต้อง **ไม่** สร้างเงิน
